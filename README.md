# Dhruvi Batra · The Resume Issue

Personal résumé website, styled as a zine-style finance magazine. Built with HTML, CSS and a little JavaScript.

## Structure
```
index.html          page content (semantic sections)
css/style.css       all styling (fonts, palette variables, flexbox/grid layout, animations)
js/script.js        small enhancements (draggable board, bookshelf caption, scroll effects)
assets/             background collage crops and sticker image
```

## Run locally
Open `index.html` in a browser. Fonts load from Google Fonts, so an internet connection is needed to see them.

## Host on GitHub Pages
1. Upload everything in this folder to the repository (keep `index.html` at the root).
2. Go to **Settings → Pages**, choose **Deploy from a branch**, select `main` and `/ (root)`, and save.
3. The site appears at `https://<your-username>.github.io/<repository-name>/`.
